# 字段、计算与口径

本地脚本支持中文列和常用英文列。最少提供消耗、展示、点击、订单或成交金额中的一项；多给一项就多一项可核对依据。不要求为了跑样例提供密钥。

| 字段 | 常用列名 | 含义 |
|---|---|---|
| 素材 | 素材ID、素材名称、creative_id | 这行对应的素材，未提供时使用原数据行号 |
| 消耗 | 消耗、花费、广告消耗、spend、cost | 广告实际支出 |
| 展示 | 展示次数、展示量、impressions | 广告被展示的次数 |
| 点击 | 点击次数、点击量、clicks | 报表记录的点击，需注明是否为目的地点击 |
| 订单 | 订单数、购买数、purchases、orders | 购买订单，不把未说明事件的转化数代入 |
| 点击归因订单 | 点击归因订单数、click_attributed_orders | 明确由点击归因的订单，用于点击转化率 |
| 成交金额 | 广告归因成交金额、成交金额、revenue | 与消耗对应范围内的广告归因成交金额 |
| 范围 | 币种、商品ID、账户、统计期、归因窗口、点击口径 | 用于拆分可比较范围 |

| 指标 | 公式 | 怎么理解 |
|---|---|---|
| 报表点击率 | 点击次数 ÷ 展示次数 × 100% | 例：10000次展示、100次点击，点击率为1% |
| 点击转化率 | 点击归因订单数 ÷ 点击次数 × 100% | 例：100次点击带来5笔点击归因订单，为5% |
| 订单/点击比 | 全部归因订单数 ÷ 点击次数 × 100% | 全部订单可能含看过广告后购买的订单，不能直接当点击转化率 |
| 每次点击花费 | 消耗 ÷ 点击次数 | 例：花100元获得100次点击，每次1元 |
| 每千次展示花费 | 消耗 ÷ 展示次数 × 1000 | 例：花100元展示10000次，每千次10元 |
| 每单广告花费 | 消耗 ÷ 订单数 | 例：花100元获得5单，每单20元 |
| 广告回报ROAS | 广告归因成交金额 ÷ 消耗 | 例：花100元带来300元成交，回报3倍；不是净利润3倍 |

汇总先加原始值再除，不能平均各行比例。字段缺失的行不补零；组内字段不齐时，已知合计附覆盖行数，对应汇总比例不计算。币种或统计范围不同的行分别展示，不混成一个回报值。

目标ROAS/CPA由用户提供，不内置行业盈亏线。CPA是同币种金额；混币种文件不套用统一目标CPA。组内参考值取可计算素材的中位数，仅用于本次样本比较。

XLSX不重算公式；关键数值为公式时提示导出为数值CSV，避免无缓存、旧缓存或外部链接影响判断。日期、币种、商品和归因口径缺失时披露，不用同一文件名证明相同口径。

## 资料来源

- [TikTok Ads Manager基础指标](https://ads.tiktok.com/help/article/basic-data?lang=en)：平台区分按展示与按点击计算的转化率，因此本包明确分母；未说明的订单/点击比不冒称点击归因转化率。
- [TikTok Shop广告归因](https://ads.tiktok.com/resources/help/article/about-tiktok-shop-ads-attribution?lang=en)：卖家中心与广告后台可能使用不同销售记录时间或归因范围，本包不混合不同统计口径。
