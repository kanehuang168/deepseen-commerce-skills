# 成品质检

可独立检查任意来源的用户授权成片，也可接收导演简版的确认要求。审核只看商品依据、确认要求和最终成片，不看作者推理或自我评分。

## 技术事实

实际读取最终文件，记录指纹、时长、画面尺寸、音轨和完整解码结果。视频可运行包内check_media_review.py；图片需另用实际读图能力，不能把视频脚本当图片审核器。

准备review.json，结构见[输入说明](references/review-input.md)，从仓库根目录运行：

```sh
python -X utf8 skills/deepseen-asset-quality-audit/scripts/check_media_review.py --media 成片.mp4 --review review.json --output 新审核.json
```

脚本只探测本地文件并核对观察契约，不自动理解画面或声音。它不下载远程媒体，不收费、不修改反馈或生成任务。写入新回执，不能覆盖历史输出。

## 内容与证据

实际看开场、关键动作中间过程、状态切换和结尾；声音要求须完整听审。按要求检查身份、数量、结构、图案、动作、台词和明确时间窗。不适用项标不适用，缺证标待核验。

无音轨却声称有人声属于证据矛盾；有音轨不等于口播正确，低音量不等于静默。抽帧可发现缺陷，但不能证明整段连续动作或全片声音通过。

换片、去音轨、拼接或确认稿修订后旧关联失效，应核对最终结果。已证缺陷和局部未核验分别保留，不用任务完成状态覆盖质量结论。

## 交付

输出简体中文结论：通过项、问题时间位置、待核验项及返修责任。允许用户保留当前结果、返修或停止；没有新生成授权与预算时不自动返修。说明实际观看与听审覆盖，不能编造观察或宣称更高销量。
