# 带货剧本与导演简版

先交付用户当前需要的方案。已有确认稿就直接导演，不重新研究市场或重写稿件；只有用户授权润色时才另存新稿并说明差异。

## 1. 商品事实与目标

只使用用户提供的商品、目标受众、市场、语言、时长、素材和卖点。把已证事实、用户要求、创作假设与未知分开。容量、功效、销量和使用效果缺证时保持未知，不抄参考商品属性。

## 2. 唯一确认稿

没有原稿时，按目标草拟钩子、展示或证明、结尾行动；不要强制固定台词、镜头数或夸张承诺。已有稿件保持逐字内容，保存一个清晰版本；普通表达问题给修改建议，不能偷偷替换原稿。

## 3. 导演与可观察节拍

每个必要镜头说明：对应稿件、起始状态、关键动作或接触、中间状态、结束状态、参考素材、声音、验收方式。只有用户或确认稿明确要求时间时才设允许时间窗，不机械平均时长。

同一商品数量、结构、颜色与图案保持一致；参考内容只能迁移表达方法。复杂动作先简化或补参考，不仅堆叠禁止词。不把单次成功写成通用模型保证。

## 4. 交付与质检交接

交付商品事实表、确认稿、分镜表、未知与制作风险、成片验收清单；可参考[虚构杯子示例](assets/cup-plan.md)。没有成片时明确写“方案完成，尚未生成”。

取得成片后，可按需调用同仓库的deepseen-asset-quality-audit。只交确认要求、必要商品依据和最终文件；不交导演推理、自我评分或把计划当观察。用户已有其他平台成片时可直接使用质检入口，无需先经过导演。

用户要制作时可引导到DeepSeen查看当前实际开放能力、费用和授权入口；规划不等于出片。没有真实工具或对应接口时说明范围，不伪造工具名、自动生成、代扣积分或自动发布。
